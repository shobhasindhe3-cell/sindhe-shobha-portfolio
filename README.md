## Features
1. Semantic HTML5 sections: Home, About, Education, Skills, Projects, Achievements, Contact.
2. Responsive mobile-first layout using CSS3 media queries, Flexbox, and Bootstrap Grid.
3. Bootstrap navbar, buttons, cards, table, forms, and alerts.
4. JavaScript ES6+ theme switching with localStorage.
5. JavaScript project filtering and skill filtering.
6. Client-side contact-form validation with dynamic success/error messages.
7. Accessible skip link, labels, ARIA attributes, keyboard-friendly controls, and reduced-motion support.
8. Back-to-top button and active navigation highlighting.
9. Modern responsive UI with light and dark themes.

## How to Run
1. Download/clone the repository.
2. Open `index.html` in a modern browser.
3. Internet access is needed for the Bootstrap CDN and Bootstrap Icons CDN.

## GitHub Deployment
1. Create a new GitHub repository, for example `sindhe-shobha-portfolio`.
2. Upload all files and folders.
3. Go to **Settings -> Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/root` folder.
6. Save and open the generated GitHub Pages URL.
